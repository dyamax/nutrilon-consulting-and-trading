# Nutrilon Consulting & Trading

This project is the website for the business, Nutrilon Consulting & Trading. The site is being developed as a digital presence for the company and is currently a work in progress.

## About the project

Nutrilon Consulting & Trading is a business focused on consulting and trading activities, with an emphasis on industrial and commercial supply solutions. The website is intended to present the company to potential partners, customers, and clients by highlighting its experience, product offerings, values, and commitment to quality, reliability, and sustainable growth.

The project currently serves as a corporate landing page and product showcase, with sections that communicate the brand, business focus, and the range of materials or goods the company deals with. The content is designed to reflect a professional trading business operating in a competitive industrial market.

## Project status

Status: Work in progress

This website is still under active development. Design, content, and sections may evolve as the business goals, branding, and product information are refined.

## Stack

This project is a static website built with:

- HTML
- CSS
- JavaScript

## Run locally

Open `index.html` in a browser, or serve the project with a simple local web server if preferred.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
